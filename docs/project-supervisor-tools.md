# 项目主 Agent 的完整项目访问

主 Agent 每轮从真实 MCP SDK 重新取得工具目录，并固定工具摘要、模型配置与 `supervisor/v3` 提示版本。旧会话继续使用当前目录；旧消息和旧工具失败保留为历史证据，不能代表当前查询结果。每轮上下文明确当前项目与默认源码。普通对话最多 20 个模型回合、60 次工具调用，整体期限仍为 180 秒。

主 Agent 可以读取当前项目全部业务记录，并通过与页面相同的正式接口操作项目：分析、任务、路径、Agent 运行、工作流、插件调用、知识发布、发现分级、报告、产物及项目管理。后台保存发送者的认证身份上下文；接口的角色要求、CAS、幂等、生命周期、预算和验证审批保持有效。管理员通过页面发起的主 Agent 对话具有当前项目的完整应用权限。此范围依据维护者确认扩展了早期只读会话设计。

## 工具与对象身份

`list_project_operations` 从应用实际路由生成可分页搜索的目录，不维护另一套接口实现。结果包含精确 `operation` 和需要填写的路径参数；项目路径参数由宿主注入。`project_api` 接受该目录中的模板及结构化参数，并调用真实处理器。任意 URL、其他项目和全局设置接口不能通过此入口调用。旧的 stdio MCP 服务仍保持原来的九个只读工具。

```json
{"search":"snapshots","limit":20,"offset":0}
```

```json
{"operation":"GET /api/snapshots"}
```

```json
{"operation":"GET /api/snapshots/{id}/graph","params":{"id":"snap-example"}}
```

源码和图谱工具的 `snapshot_id` 在模型侧为可选参数。省略时宿主使用会话的默认源码；显式指定时必须属于当前项目。`inspect_project`、源码正文和文件目录使用所选快照；结果保留实际快照身份。查询另一份项目内历史输入不会改写会话、旧运行、图谱版本、报告或证据的绑定。

任务使用 task/audit ID，路径使用 path ID，路径 Agent 使用 run ID，四阶段分析使用 analysis_run ID，DAG 使用 workflow_run ID，插件调用使用 invocation ID；这些身份不能互换。主会话使用 session ID 与独立 supervisor run ID。目录中的参数名及正式 API 错误决定对应身份，指定 ID 的详情调用不会被替换成列表。

常用详情目录可搜索 `tasks`、`paths`、`runs`、`agent-sessions`、`workflow-runs`、`analysis-runs`、`plugin-invocations`、`findings`、`evidence`、`reports`、`artifacts` 或 `knowledge`。旧式无项目路径的对象接口会先核对对象所属项目；全局式运行、假设、验证、发现和审计列表强制使用项目内快照过滤。旧多输入项目可显式选择项目内快照，不擅自猜测最新输入。

## 真实操作与失败

读取响应保留 `status`、`ok`、`etag`、来源操作和项目身份。写操作使用相同的 JSON 请求、`if_match` 与 `idempotency_key`；异步创建只表示请求已受理，必须进一步查询终态。

```json
{"operation":"PATCH /api/projects/{id}","if_match":"\"project-1\"","body":{"description":"新的项目说明"}}
```

ETag 必须来自刚读取的真实响应，示例不能代替实际值。HTTP 失败同时标记为 MCP 工具失败；结构化状态与错误码仍回灌模型并保存在会话工具结果中。跨项目、未知对象、不支持、预算、损坏和存储不可用不能当成空成功。

## 大内容、固定版本与校验

报告详情与产物正文沿正式 API 和 ArtifactStore 读取，产物先核对大小及 SHA-256。响应通过流式窗口返回，模型单次只收到最多 4000 字节的内容，最坏 JSON 转义仍在结果预算内；整份响应的摘要和总字节数仍可见。完整小型 JSON 放在 `data`；大响应放在 `content`，明确标为 `text_window`，二进制放在 `base64_window`。窗口片段不能当作完整 JSON 或全部覆盖。

GET 调用可用 `response_offset=next_offset` 继续，并携带上一页的 `expected_sha256`。摘要变化返回 `view_superseded`，不能把两个版本拼接。UTF-8 窗口保持字符完整；二进制偏移仍按原始字节计算。写请求不能用响应偏移重复执行。

会话、工具调用、工具结果及正式接口产生的记录沿现有 PostgreSQL 仓储持久化。应用重建后重新取得当前能力，旧运行的工具摘要、消息和结果保持可读。
