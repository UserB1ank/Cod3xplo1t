# 插件中心界面

日期：2026-10-23。界面沿用正式工作区的浅色与墨绿设计，保留项目导航与插件中心路由。

页面分为三个视图：

- **插件目录**：左侧按十个阶段筛选，右侧提供名称 / ID 搜索和状态筛选。插件按逻辑 ID 聚合多个版本，优先展示当前可执行版本，再选择已安装或最新登记版本。清单版本和运行可用性独立。
- **调用记录**：按项目与固定快照读取真实调用，展示终态、覆盖未知值、输入、产物和来源。新协议与兼容调用共用历史；运行中的计数显示待报告，不把初始化的零值写成覆盖完成。
- **接口标准**：从后端阶段目录读取必需输入输出，可下载各阶段的清单开发模板。领域服务、进程协议和原生二进制的接入范围单独说明。

点击插件打开详情抽屉，包含概览、输入与输出、安装与版本三个页签。完整性、功能实测、安装和启用状态分别呈现；完整摘要可复制，平台发行和 worker 安装记录来自真实 API。安装、检查、启停及卸载保留权限和 CAS；内置工具只展示适合其领域的操作。新协议执行表单按 operation 显示绑定输入和参数，旧适配器使用兼容执行表单。

接入清单、执行参数及标准 Schema 按需展开，不占据默认目录。错误保持真实并提供重试，不以演示数据替代。界面提供加载、空目录、无匹配、不可用与只读状态，使用原生 dialog 维持焦点与 Escape 行为；页签支持左右方向键和 Home/End。窄屏阶段导航横向滚动，目录表格限制在内部滚动容器。

开发与运行说明见 [分阶段插件手册](plugins-v2.md)，实现验收见 [v2 验收记录](design/plugin-system-v2/validation.md)。
