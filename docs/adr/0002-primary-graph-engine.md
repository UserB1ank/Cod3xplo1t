# 0002：项目默认图谱分析使用一个整体引擎

- 日期：2026-10-23
- 状态：已接受

项目默认链路采用固定 Joern 发行物，统一执行 CPG 构建、污点查询、候选生成和确定性排序。各阶段独立记录、取消和恢复，复用同一 CPG 与标准事实。项目页提供一键入口；替换插件中心的安装状态不会改写历史运行。

整体扩展边界为 `analysisengine.Provider.Workflow / Project`。其他引擎须同时提供正式工作流和规范化审查投影，提升默认 profile 版本；当前不建设逐阶段任意混搭的工具选择机制。独立扫描器、Agent、验证和报告保持独立扩展。

运行固定源码、插件 / 构建摘要、规则配置、图谱引用和原始证据。失败明确终止或跳过下游，不回退到 Go。旧运行、发布记录和产物保持不可变；新构建使用摘要绑定的 Build ID，新默认仅在新运行中生效。

实现、状态机、部署和验收见 [项目主图谱引擎](../analysis-engine.md)。
