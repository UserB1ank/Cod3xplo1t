## 走查范围与方法

通过正式服务中的 termcp 项目，实际操作项目总览、代码图谱、主/子 Agent 工作台、发现与证据、报告和插件中心。路径错位沿用本轮会话已取得、现已登记在 #72 的正式页面复现。记录 CSS 视口为 1113 × 895，通过截图、可访问树、可见 DOM 几何与计算样式交叉核对，再查对应代码。

检查以实际任务为单位：判断现在做到哪里、选择需要审查的内容、阅读代码及结论、查询记录、阅读报告、准备工具调用。关注视觉负担、操作精度、滚动和视线移动、记忆负担、状态辨认及恢复路径。

本轮未完成窄屏、200% 缩放或全部键盘路径的实际测试；这些列为交付验收要求，不能写成已测通过。没有重新运行分析或模型，也没有提交插件执行表单。发现页当前无真实漏洞记录，因此未据此声称已经检查其非空详情的所有分支。

## 结论与优先级

目前存在多处直接妨碍任务完成的问题：路径正文被挤到零宽；图谱只能读到函数声明；主 Agent 旧会话无法提供当前记录；报告超大且没有正常排版。另有持续使用负担：小字和低对比文字、原样显示 Markdown、结果淹没在日志中、通用名称与长 ID、表单和目录顺序不符合当前任务。

## 保留已正确的行为

- 当前图谱化分析明确显示部分覆盖，历史失败保留；调整信息层级不能把它们改成“完整成功”。
- 导航的当前页面有 aria-current；本次 DOM 核对为单一当前页，不能仅凭悬停底色报成多个当前页。
- 插件详情使用原生 dialog，关闭后焦点回到原插件入口；图谱节点有可访问名称与键盘操作入口。
- 空发现页已说明“任务结束也可能没有发现漏洞”；继续补充工作进展和下一步，不将零发现改成报错。
- 项目作用域、固定输入、版本和完整性信息继续保留，通过渐进展开降低阅读负担，不删除证据元数据。

## 可量化的共同验收基线

以下基线要在每个实际任务切片中交付，不能只增加一份 token/CSS 文件就算完成。

1. **阅读尺寸**：建议普通正文、表单和主要操作至少 14px；连续对话/结论 16px；辅助标签至少 12px；代码默认至少 14px并可放大。这是本项目的可用性目标，WCAG 并未规定统一的最小字号。长段落控制阅读宽度，中文行高建议 1.6–1.9；关键状态不依靠浅色小字。
2. **对比度**：普通文字至少 4.5:1，大字至少 3:1，按真实前景、背景与透明度计算；禁用、装饰等例外单独判断。[W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
3. **操作尺寸**：非内联控件至少覆盖 24×24 CSS px，或严格验证间距等适用例外；项目建议常用控件至少 32px 高，主要触控操作尽量达到 44px。不能用视觉图标尺寸替代实际点击范围。[W3C 最小目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
4. **缩放与重排**：文字放大至 200% 不丢内容或功能；320 CSS px 宽的普通内容可重排，不要求来回横向滚动阅读。图、代码长行与数据表等必要二维区域可以局部滚动，页面主操作仍可达。[文字缩放](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)、[内容重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)
5. **键盘与定位**：Tab/Shift+Tab 可达主要操作且焦点可见；弹窗关闭后恢复触发点；返回列表保留选中项、页码和适当滚动位置。长会话阅读历史时，新消息不抢走阅读位置；返回最新有明确入口。
6. **状态与恢复**：先说明对象、状态、结果、影响和下一步，再提供机器错误码、ID、摘要和协议详情。加载、空、无权限、不支持、失败和过期分别表达，失败不回退演示成功。
7. **真实使用验收**：至少检查 1440×900、1366×768、当前 1113×895、窄屏及 200% 缩放；记录真实 PG/API 的屏幕、点击/键盘路径与结果。截图审查和实际操作都需要，不能只跑静态 DOM 断言。

## E1：主 Agent 对话支持舒适阅读、结构化展示和连续操作

### What to build

**类型：AFK。用户故事：US6。**

用当前真实主会话完成“读上一轮 → 理解工具结果 → 继续输入”的闭环。为长答复、Markdown、工具结果和本轮信息建立明确层级，解决小字、多重滚动和输入操作不便。继续开放对话，不用预设意图按钮替代模型决策。

### Acceptance criteria

- [ ] 正式历史消息以安全 Markdown 排版阅读：表格、标题、列表、代码与链接可用，原始 HTML/脚本不执行；工具调用/结果仍可逐项追溯，不把工具 JSON 当自然语言结论。
- [ ] 正文、输入、状态及摘要达到共同尺寸/对比度基线；16px 连续阅读时主要内容有足够宽度，长 ID/代码只在自身区域处理溢出。
- [ ] 主要会话区和输入操作形成稳定布局；长历史、长工具结果、短屏/缩放时均可找到输入、发送和当前状态。查看历史时不会被新消息强制拉到底部，可主动回到最新。
- [ ] 工具摘要先展示中文动作、对象、成功/失败/截断及时间，调用 ID/参数/原始结果渐进展开；历史结果与本轮结果区别明确，不能把旧 not_found 标成刚查询。
- [ ] 保留回车发送、Ctrl+回车换行及中文输入法行为；发送中、失败重试、未发送草稿和焦点有真实反馈，重试沿现有幂等语义，不重复创建消息。
- [ ] 使用真实 PG 持久会话验收刷新/重启、长历史、模型不可用、工具错误和键盘流程；实际新工具查询恢复归 #73/#74，不依赖其完成才改善已有记录的阅读。

### 实现切入点

`web/src/Assistant.tsx`、工作台样式、会话客户端与公开事件字段。复用现有运行记录，缺少必要展示字段时交付最小契约/服务接线，不新增会话引擎。

### Blocked by

无，可立即开始。

## E2：子任务工作台优先展示审查结果与当前运行上下文

### What to build

**类型：AFK。用户故事：US7。**

从路径子任务列表选中一项后，先看到审查对象、当前运行、结果与未决义务，再按需看执行日志。任务目录提供能辨认的名称，当前子运行的用量和证据与主会话信息清楚区分。

### Acceptance criteria

- [ ] 列表以简短入口→敏感操作/文件位置及状态辨认任务，稳定 ID 作为辅助；同名、多次运行、暂停和失败可区分，不按标题合并任务。
- [ ] 已完成项首要内容来自宿主已接受的结构化答案：中文状态、是否形成候选、义务完成/未知与阻碍、支持/反对/未决证据。缺答案显示未记录，不能从日志里任取文本伪造答案。
- [ ] 已固定中文展示稿存在时复用；模型原文与原始事件可独立查看，显示层不重新审判或修改裁定。报告本身的中文模板与历史翻译归 #71，工作台不另建报告账本。
- [ ] 默认折叠低价值协议日志，按中文动作/阶段查看，错误和重要事件可定位；已有真实事件不被删除。任务失败与审查证据不足、执行完成与漏洞确认分别显示。
- [ ] 当前运行 ID、所属任务/path、运行时、模型、用量、停止原因与所选子任务一致；主 Agent 信息留在明确的独立区域，不让用户自行猜测归属。多次运行可切换、刷新后可恢复选中项。
- [ ] 从结果进入真实证据/源码/任务详情，再返回原项；字体、目标尺寸、缩放、长文本和键盘满足共同基线。#68 尚未接入时保留明确的消息能力说明，不显示假对话输入。
- [ ] 以 termcp 的真实完成/暂停任务及确定性失败/无答案数据完成 API、PG 重启和浏览器验收；不可仅将执行日志改个标题交付。

### 实现切入点

工作台子任务投影、现有 Agent run/Answer/义务及证据查询、`web/src/Assistant.tsx`；补齐 reader 详情接线和正式来源链接，复用已有身份映射。

### Blocked by

无，可立即开始。与 #71/#74 的后续中文展示与主 Agent 读取保持同一来源。

## E3：图谱入口到源码与证据形成连续阅读闭环

### What to build

**类型：AFK。用户故事：US8。**

从入口目录选到节点后，能够连续读取该固定快照的源码上下文，检查来源及关系证据，再返回原目录/图位置。消除仅有函数声明、窄目录长名称和不可辨同名记录带来的断点。

### Acceptance criteria

- [ ] termcp 的 NewManager 不再只显示第 54 行声明；初始提供有界上下文，支持继续向前/向后读取和进入完整文件。函数结束位置未知时明确按行窗口阅读，不伪造函数边界。
- [ ] 源码由固定快照内容读取并核对归属；图未发布/位置不完整时区分源码可用与图不可用。跨快照、缺文件、越界、超限和无权限返回真实状态，不用最新工作区代码补旧证据。
- [ ] 目录优先显示简短符号名与文件位置，完整限定名可查看/复制；同名项展示足以区分的来源/规则/版本。若按 canonical 身份分组，只改变展示且保留所有观察与原 ID，不静默合并不同事实。
- [ ] 合理分配目录、图和源码阅读空间，长目录不将右侧撑成大片空白；搜索、分页、图展开和源码窗口有明确界限。必要二维区域局部滚动，普通文字重排，代码默认可读并可调整。
- [ ] 节点/关系选择与源码高亮对应；展开、来源/未解析说明、源码和返回操作可用键盘完成。返回保留入口、搜索/页码、图层/固定版本与阅读位置。
