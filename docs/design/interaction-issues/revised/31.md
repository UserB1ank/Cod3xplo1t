**类型：AFK**

**用户故事：** 管理员可以选择已授权环境模板，创建受控环境、执行无目标代码的诊断探针、查看实际限制并销毁环境。

## What to build

复用 #21 的受控 worker，新增与扫描插件分离的 EnvironmentProvider，交付一个真实容器供应适配器。正式环境页贯通创建、状态、只读快照输入、受控探针、证据采集和销毁，并将实际施加的限制保存为 EnvironmentReceipt。

## Acceptance criteria

- [ ] 版本化协议实现 DescribeCapabilities、ValidateSpec、Provision、Inspect、RenewLease、Exec/StartService、Collect、Destroy、Reconcile；Reset 可声明不支持。Provision 返回异步操作 ID，命令与服务操作使用结构化参数及服务角色。
- [ ] 创建请求幂等且绑定 scope、模板摘要和请求摘要；返回有限权限环境句柄，不暴露宿主路径、基础设施密钥或管理 socket。
- [ ] 凭实际 worker 能力强制源码只读、scratch、CPU/内存/进程/磁盘/期限及网络策略；不满足要求返回 unsupported。Receipt 同时记录 requested/applied、供应器/模板版本、实际镜像摘要、worker 和环境 ID。
- [ ] 认证 API 与正式 UI 完成真实创建→就绪→只读诊断探针→日志/测试产物→销毁，reader/writer/admin 权限和项目隔离明确；本单不授权执行目标仓库代码。
- [ ] 正常、创建中失败、取消、超时均进入清理，Destroy 幂等；环境状态与清理状态分开记录，失败不能虚报已销毁。
- [ ] 独立 worker 实测资源/网络/文件访问限制、损坏产物、重复请求和迟到写入拒绝；持久化与重启读取、部署文档及页面验收通过。跨 worker 重建回收由 #34 扩展。

## 共同交付约束

- 每单交付可独立演示的真实行为，包含版本化 Schema、领域逻辑、认证 API、正式 UI、持久化、文档及验收；底层接口不能单独作为完成条件。
- 兼容现有 API、插件版本、计划、产物与证据 ID。新增契约采用明确版本和迁移策略，不修改已发布版本的字段含义；新计划不得替换旧 pin。
- 新业务以 PostgreSQL 为唯一维护后端，Memory 可作测试双，SQLite仅保留历史读取/迁移；真实环境与worker集成必须使用真实后端验收，不能以mock证明隔离。
- 静态扫描保持不执行目标 build/test/hook；构建、安装依赖、运行目标、动态验证分别使用明确授权。动态审批绑定规范化计划摘要、源码与环境摘要、目标及权限，不能由插件或模型自报批准。
- Agent 无基础设施管理凭据、任意 shell 或宿主管理 socket。凭据仅使用引用和短期注入，不进入清单、事件、日志或报告。
- 有效权限为清单、安装授权、任务策略与实际可强制能力的交集。插件自身 runtime 与目标环境 backend 分开建模。
- 观察与最终裁定分离；宿主验证证据后派生状态。未复现、超时、环境故障、能力不足不能自动判为 refuted；退出码为零或文本匹配不能单独证明漏洞成立。
- 相关公开边界按 TDD 逐项 red → green，新边界依技能确认；遵循 AGENTS.md 的竞态、稳定性、lint、契约、前端测试/构建与文件系统/生命周期压力测试要求。Go 单元测试兼容三 OS；真实外部后端测试提供隔离入口并明确平台前提。
- 不提交敏感信息、实际环境数据、凭据文件或私钥。AFK/HITL 描述实现所需决策，不改变提交及 push 授权。


## 当前原型对齐（2026-10-21）

环境供应是独立后端插件，不是主Agent进程。与 #21/#30 原授权和评论保持一致；由宿主登记的环境/租约/API供主Agent查看状态，创建/销毁仍需原能力与计划授权。主Agent工作台显示执行/回收状态，不能以模型文字宣布环境就绪。


## 本轮开发共同约束（2026-10-21）

本单已按当前前端原型与主 Agent 设计修订。新项目是一份源码的一次审计，创建时隐含保存输入；默认一键四阶段传统分析。主 Agent 使用自由对话，由模型自主选择 MCP 工具，禁止用户指令类型枚举、关键词路由及固定工具序列替代模型决策。实际进程、scope、权限、预算、幂等、租约和证据校验仍由宿主负责。

复用已交付 Go / Pi / llm、插件、工作流、PG、认证和证据能力，保留旧 API / ID / 固定版本与历史项目。新业务仅维护 PostgreSQL，Memory 可作测试双；SQLite 仅历史读取或迁移源，不新增 SQLite 功能/CI门槛。原型是模拟数据，不能进入正式执行或作为真实验收证据。

交付必要的契约、真实后端、认证 API / MCP、正式 UI、PG持久化、文档与验收。遵守 AGENTS.md：确认公开边界后逐项 TDD，相关测试、完整乱序竞态、make lint、make check-contracts、前端测试/构建；PG改动跑 make test-postgres，文件系统/生命周期跑 make test-stress。不得改动他人WIP或排除失败包后宣称全量通过。验收后的 commit/关闭按既有授权流程，push 仍须用户明确要求。秘密、个人信息、.env和私钥不得入库。

产品主线 #63–#69；架构 docs/design/project-agent-architecture.md；接手顺序 docs/design/deepseek-handoff.md。本单原有动态执行审批与现有人工授权边界继续有效，开放对话不意味着模型可以自授权限。
