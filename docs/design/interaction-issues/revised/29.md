**类型：AFK。用户故事：** 一键图谱化的第四阶段自动筛选并排序路径，我能查看保留/过滤原因；高级用户仍可在自定义工作流使用同一插件。

## What to build

交付真实确定性路径过滤/评分插件，从固定知识视图及明确上游 discovery.paths 读取，输出稳定路径、增强 lineage、评分和选择说明。它是 #64 默认四阶段链路的第四阶段，也能在高级工作流显式串接；默认不依赖模型。Agent主动作路径发现是 #67，不用该插件的固定规则冒充模型决策。

## Acceptance criteria

- [ ] 输入固定原始路径、snapshot/图层pin、上游producer、配置和预算；保留原path_id与增强来源、特征/权重版本、原因和截断信息。
- [ ] #64 可选定实际增强节点/版本自动消费，其输出才被后续发布/分析使用；不能改取latest或未选分支。高级工作流编辑、输入/输出对比继续可用。
- [ ] 有界只读图查询补充既有事实，限定项目/input/view/预算；不向插件开放任意数据库查询、宿主路径或外部网络解析。
- [ ] 不伪造端点/调用/证据，call_reachability/hypothesis不提升为taint_flow/verified；优先级不是严重度，过滤不是安全证明。
- [ ] 正式路径页读筛选/过滤原因、评分版本和局限，来源与后续 #67 Agent 发现区分；无规则候选不按标题并入发现组。
- [ ] 重试幂等、跨输入拒绝、缺证据、预算截断、取消迟到输出、PG重启lineage和真实默认/自定义工作流执行验收通过。
