## What to build

**类型：AFK**

**用户故事：** 重建应用容器后，仍可读取源码、图谱输入、扫描报告与证据。

为 ArtifactStore 接首个独立文件 / 对象服务后端，提供 Docker 数据卷、内部网络和运行时凭据引用。让正式快照、插件输出和下载页面走相同引用，应用工作目录仅作可重建缓存。

实现基线：`f2867db`；接口方案：`docs/design/interfaces/v1/`；实施映射：`docs/design/interfaces/v1/10-adoption.md`。

## Acceptance criteria

- [ ] 创建快照与实际分析产物后销毁验收环境的应用缓存，重建应用仍可执行任务和授权下载原内容。
- [ ] 暂存 → 摘要校验 → 元数据发布的恢复顺序正确，崩溃不产生可见半成品，引用中产物不被回收。
- [ ] 解包拒绝绝对路径、穿越、链接逃逸和超限展开；读取有预算，缺失 / 损坏在页面明确呈现。
- [ ] 真实服务测试流式限额、重复写入、发布中断与回收，逻辑 ArtifactRef 身份不改变。

## 共同约束

- 保留已实现的登录、应用内 LLM 设置、项目任务、现有分级和 CLI / MCP。下面的任务负责接线或扩展，不重复建设。
- 每单交付可独立演示的用户操作：必要的持久化和 Schema、领域逻辑、认证 API、正式 UI、测试与文档一起完成。不能只交付一个无人使用的底层接口。
- 接线按功能逐页进行，公开 `/prototype/` 继续隔离演示数据。正式页面不得在失败时退回模拟成功。
- 保留现有项目、快照、符号和证据 ID；旧 `/api` 兼容。新增 `/api/v1` DTO 经公共 Schema 校验，授权同时检查项目与快照归属。
- 所有发现仅有 high / medium / low 严重性；未评估可缺省。严重性、确认状态和证据等级独立；不包含修复工单、补丁或复测流程。
- 插件与目标仓库代码分别授权；v1 不执行目标项目的 build、test、hook 或安装脚本。
- AFK 表示无需额外产品决策即可实现，仍须遵守 AGENTS.md 对 commit / push 的人工授权要求。HITL 有明确的人工验收节点，不代表每一步都需要等待。
- Go 测试需兼容 Ubuntu、macOS、Windows，遵守临时目录与并发约束；运行相关测试、`make lint`、前端测试和构建。真实 PG / 外部服务另跑隔离集成测试，不能只用 mock 宣称支持。
- 不提交真实凭据、个人信息、运行数据、`.env` 或私钥。LLM 配置继续在程序内管理，部署文件只保存凭据引用。


## 当前原型对齐（2026-10-21）

本单继续负责独立产物后端，不阻塞 #63–#69 首轮使用现有 ArtifactStore。新增项目隐含输入、分析产物、主子任务证据和固定报告沿同一 ArtifactRef 读取；会话/工具事件属于PG，不能把原始模型会话/隐藏推理当必需产物。删除与回收遵守项目/输入/运行引用栅栏。


## 本轮开发共同约束（2026-10-21）

本单已按当前前端原型与主 Agent 设计修订。新项目是一份源码的一次审计，创建时隐含保存输入；默认一键四阶段传统分析。主 Agent 使用自由对话，由模型自主选择 MCP 工具，禁止用户指令类型枚举、关键词路由及固定工具序列替代模型决策。实际进程、scope、权限、预算、幂等、租约和证据校验仍由宿主负责。

复用已交付 Go / Pi / llm、插件、工作流、PG、认证和证据能力，保留旧 API / ID / 固定版本与历史项目。新业务仅维护 PostgreSQL，Memory 可作测试双；SQLite 仅历史读取或迁移源，不新增 SQLite 功能/CI门槛。原型是模拟数据，不能进入正式执行或作为真实验收证据。

交付必要的契约、真实后端、认证 API / MCP、正式 UI、PG持久化、文档与验收。遵守 AGENTS.md：确认公开边界后逐项 TDD，相关测试、完整乱序竞态、make lint、make check-contracts、前端测试/构建；PG改动跑 make test-postgres，文件系统/生命周期跑 make test-stress。不得改动他人WIP或排除失败包后宣称全量通过。验收后的 commit/关闭按既有授权流程，push 仍须用户明确要求。秘密、个人信息、.env和私钥不得入库。

产品主线 #63–#69；架构 docs/design/project-agent-architecture.md；接手顺序 docs/design/deepseek-handoff.md。本单原有动态执行审批与现有人工授权边界继续有效，开放对话不意味着模型可以自授权限。
