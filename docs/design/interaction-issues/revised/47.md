- [ ] 合同保持不可变，保存输入、合同版本/摘要、覆盖目标及允许人工复核策略；改变合同创建新的审计轮次和血缘，不改旧记录。

- [ ] 纯函数返回完成与未达标原因：入口覆盖、必需sink、未知/未解析、任务状态、frontier、未批准预算暂停；换runtime不改变同账本判定。
- [ ] 四阶段完成、探索结束、子run结束、覆盖达标和漏洞确认分别表示；未知/缺证据/paused/stopped/failed不能聚合成成功。
