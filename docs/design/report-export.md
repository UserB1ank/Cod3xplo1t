# 固定版本报告：前端与接口实施提案

状态：Issue #14 已接线。正式任务页与项目页使用固定报告；旧即时导出接口继续兼容。
实际接口、预算和恢复语义见 [固定版本报告](../reports.md)。

## 用户入口

沿用正式工作区的深色表格、绿色操作色和现有 React / TypeScript 组件。
任务内保留“报告”标签；项目导航增加“报告”，两处使用同一份生成器和历史目录。
任务入口固定任务及其快照；项目入口先选择一个代码源快照，再聚合该快照下的任务。
项目范围明确标为“项目 · 此快照”，不会把多个代码版本合成一个未声明的基线。

```text
项目 / 任务 / 报告                         [刷新]
固定输入                                  已保存报告
┌──────────────────────────────────────┐  ┌───────────────────────┐
│ 范围       当前任务 / 项目 · 此快照   │  │ 时间 / 格式 / 状态    │
│ 源码       来源、快照、实际提交       │  │ 固定输入、知识版本    │
│ 知识       固定视图、发布版本         │  │ 发现数、候选策略      │
│ 格式       Markdown / JSON / SARIF    │  │ 摘要、大小、来源      │
│ 候选       □ 包含待验证候选           │  │ [查看] [校验并下载]   │
│                                      │  └───────────────────────┘
│ [生成并保存报告]                      │
└──────────────────────────────────────┘
报告详情：固定范围 → 计数 → 来源与覆盖 → 有界内容预览
```

宽屏采用主表单加历史目录；窄屏按“固定输入 → 生成状态 → 历史目录”排列。
生成、取消、查看和下载是独立动作。修改表单不会改变已保存报告，也不会重新生成已选历史项。

## 固定输入与内容

源码快照、图谱视图和发现账本分别表达。选择旧知识版本不代表恢复了当时的发现裁定。
生成时保存发现及分级版本、观察来源、证据、路径和任务覆盖的输入文档，并标明采集时间与摘要。
报告记录所选知识版本；不能归入该版本的来源必须明确说明，不能伪称来自所选视图。

| 内容 | 展示与导出规则 |
| --- | --- |
| 范围 | 项目、来源、快照、提交；任务范围另含任务 ID、名称、目标与种子范围 |
| 知识 | 固定 SCG / ASG 视图及显式选择的共享发布版本；未发布时明确显示 |
| 发现 | 沿用 #13 指纹分组，保留成员、观察与分级审计版本，不按标题再次合并 |
| 候选 | 默认排除；勾选后单列候选计数，不能并入已确认漏洞数 |
| 严重性 | high / medium / low；未评估显示待分级，与确认状态独立 |
| 确认状态 | candidate / confirmed / refuted / inconclusive / blocked 分别保留 |
| 证据 | 支持、反对、未决分别列出，保留工具版本、位置、摘要及引用 |
| 路径 | 保留 path_kind、步骤、图层版本、开放问题与局限；调用可达不写成数据流 |
| 覆盖 | 按任务保留真实覆盖、跳过数量与截断原因，不用发现数推算覆盖率 |
| 产物 | report.document、格式、字节数、SHA-256、reporter 版本和调用 ID |

报告分页聚合在服务端完成。页面展示的当前页不是报告输入；超过预算时拒绝生成，
不通过截掉尾页而显示成功。计数基于过滤后的完整分组集合，并在三个格式中一致。

## 状态与交互

| 状态 | 页面行为 |
| --- | --- |
| 尚未选择快照或视图 | 说明缺失项，禁用生成 |
| 输入固定中 | 保留选择，显示进度；错误就地呈现 |
| CREATED / RUNNING | 显示 reporter 调用及预算，允许有权限的操作者取消 |
| SUCCEEDED | 显示完整不可变引用，开启内容预览与下载 |
| FAILED / TIMED_OUT / CANCELLED | 显示真实状态与可操作原因，不提供成功产物 |
| 重启中断 | 沿用插件宿主的中断状态，不用空报告代替 |
| 证据缺失、Scope 不符或内容损坏 | 明确失败；不能只保留结论而声称证据完整 |
| 下载校验失败 | 阻止保存，显示摘要或大小不一致；原产物保持不变 |
| 无匹配发现 | 可以生成零发现报告，同时保留范围、候选策略和覆盖局限 |

预览将 Markdown 作为文本显示，不执行 HTML；JSON / SARIF 使用有界文本预览。
下载通过现有认证 ArtifactStore 接口获取，复核字节数和 SHA-256 后再保存到浏览器。
reader 可查看和下载；生成与取消要求 writer。请求失败不会切换到原型或演示数据。

## 接线

新增项目范围的 `/api/v1/projects/{projectID}/reports` 创建与分页目录接口，
以及单项状态读取接口。请求显式携带快照、可选任务、固定视图、格式、候选策略和预算。
响应使用公共 Schema 校验，包含 reporter 调用状态和成功后的产物引用。
取消复用插件调用的 CAS 取消；内容与下载复用快照产物接口，继续校验项目与快照归属。

reporter 以宿主内置的版本化插件登记，消费保存的固定输入，产出一个 report.document。
成功状态与产物引用使用现有调用存储的原子发布机制；不把报告当作扫描候选再规范化。
旧 `/api/audits/{id}/report` 继续兼容，正式新页面使用保存后的产物。

## 已确认的 TDD 边界

1. 从认证 API 固定真实输入，完整聚合分页发现及证据，生成三个格式的不可变报告。
   验证候选策略、分组计数、图谱 / 工具来源，以及后续发现和分级变化不影响旧报告。
2. 从正式任务与项目页面生成、查看、取消及授权下载。
   验证摘要、SQLite 重启恢复、跨项目拒绝，以及取消、超限和缺失证据明确失败。

浏览器验收使用隔离服务和合成代码源，覆盖两个入口；运行数据和访问凭据不进入仓库。
