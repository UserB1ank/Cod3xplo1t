## 范围与共同行为

- 保留已实现的登录、应用内 LLM 设置、项目任务、现有分级和 CLI / MCP。下面的任务负责接线或扩展，不重复建设。
- 每单交付可独立演示的用户操作：必要的持久化和 Schema、领域逻辑、认证 API、正式 UI、测试与文档一起完成。不能只交付一个无人使用的底层接口。
- 接线按功能逐页进行，公开 `/prototype/` 继续隔离演示数据。正式页面不得在失败时退回模拟成功。
- 保留现有项目、快照、符号和证据 ID；旧 `/api` 兼容。新增 `/api/v1` DTO 经公共 Schema 校验，授权同时检查项目与快照归属。
- 所有发现仅有 high / medium / low 严重性；未评估可缺省。严重性、确认状态和证据等级独立；不包含修复工单、补丁或复测流程。
- 插件与目标仓库代码分别授权；v1 不执行目标项目的 build、test、hook 或安装脚本。
- AFK 表示无需额外产品决策即可实现，仍须遵守 AGENTS.md 对 commit / push 的人工授权要求。HITL 有明确的人工验收节点，不代表每一步都需要等待。
- Go 测试需兼容 Ubuntu、macOS、Windows，遵守临时目录与并发约束；运行相关测试、`make lint`、前端测试和构建。真实 PG / 外部服务另跑隔离集成测试，不能只用 mock 宣称支持。
- 不提交真实凭据、个人信息、运行数据、`.env` 或私钥。LLM 配置继续在程序内管理，部署文件只保存凭据引用。

编号不表示所有任务串行执行。D15 在 D01、D04 后即可与插件和工作流线并行推进。未完成的 PostgreSQL 能力保持 unavailable / unsupported，不把 SQLite 静默作为另一个权威写入源；完整验收前不宣称生产可切换。

## D01 — 本地文件夹代码源生成真实快照并创建任务

类型：AFK。用户故事：用户选择已挂载文件夹，生成快照后启动独立任务。

### What to build

将本地文件夹表单接到显式 `local_folder` SourceProvider，持久化项目内代码源定义与版本，冻结源码并让正式任务创建页选择该快照。目录内存在 `.git` 时仍按文件内容读取。适配旧项目的默认代码源。本单沿用现有任务运行方式，自定义 workflow_ref 在 D10 接线，不能为通过新 Schema 填入虚构工作流。

### Acceptance criteria

- [ ] 正式 UI 新增本地代码源、生成真实快照、创建任务，重启后记录可读。
- [ ] 项目可拥有多个代码源；任务固定 source / snapshot，更新代码源不会改变已有任务。
- [ ] API 校验公共 Scope；越界挂载、链接逃逸、复制期间变化不会发布可用快照，覆盖局限可查看。
- [ ] 新旧 API 兼容；测试覆盖内容变化、拒绝路径和跨项目访问。

### Blocked by

None - can start immediately.

## D02 — Git 仓库固定提交并创建可复现任务

### Acceptance criteria

- [ ] 新增 Git 代码源、解析 ref、生成快照与创建任务形成完整路径；分支后续移动不影响已有快照。
- [ ] 仓库 URL 不含凭据；凭据引用、网络策略和源定义版本由服务端校验。
- [ ] 不运行 hook、仓库脚本；获取失败、无权限、提交不存在与覆盖局限在页面区分。
- [ ] 合成本地 Git 远端测试无需真实账号；测试网络拒绝、幂等与跨项目隔离。

## D11 — 工作流暂停、取消、重试和重启恢复

类型：AFK。用户故事：用户控制活动任务，并能在应用重启后恢复执行而不重复发布结果。

### What to build

把正式任务控制接到流程运行状态机，持久化节点租约、栅栏、重试预算和事件游标。页面区分暂停中、已暂停、取消中与终态，并持久化并发策略。

### Acceptance criteria

- [ ] 暂停阻止新节点领取，活动节点在边界完成；取消等待执行器终态或租约回收。
- [ ] 只重试 retryable 错误，退避、最大次数和总预算明确，取消不自动重试。
- [ ] 重启与租约失效可恢复；迟到 worker 输出被拒，已提交产物不重复发布。
- [ ] 故障和并发测试验证状态 / 事件一致、并发限制、重复请求和游标恢复。
